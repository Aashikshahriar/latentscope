# Reproducibility

## What is recorded

Every projection creates an experiment record (stored locally in IndexedDB) containing:

- dataset identifier, name and **SHA-256 checksum** (over shape, float32 values and identifiers);
- algorithm, implementation name and version (`latentscope-pca` / `latentscope-tsne` at the
  application version, or `umap-js 1.4.0`);
- all parameters, including the **random seed**;
- the preprocessing configuration, including subsample size, seed and the selected row indices;
- output dimensionality, diagnostics (PCA method and explained variance, t-SNE KL history and
  effective perplexity, UMAP neighbour method and epochs);
- quality metrics with their k, sample sizes, seeds and approximation flags;
- runtime, timestamp, application version and browser environment.

## Randomness

All stochastic steps draw from Mulberry32 generators seeded through SplitMix32
(`src/utils/rng.ts`): t-SNE random initialisation, UMAP (passed to umap-js as `random`), k-means++
seeding, subsampling, randomized PCA, and every sampled metric. Nothing uses `Math.random()`.

For the same dataset checksum, parameters, seed and LatentScope version, a run reproduces the same
coordinates. Different browsers or CPUs may differ in the last bits of floating-point results
(e.g. `Math.exp`), which can occasionally change t-SNE/UMAP layouts slightly; quality metrics are
stable to many decimals.

## Exports

- **Figures** (SVG/PNG) carry the reproducibility record in-file (SVG `<metadata>`, PNG `iTXt`
  chunk with keyword `LatentScope`) and as a sidecar `*.metadata.json`.
- **Coordinates** (CSV/JSON) preserve observation identifiers; JSON includes the record.
- **Sessions** (`latentscope.session`, schema version 1) contain the experiment, coordinates,
  metrics, view settings, selection (by identifier) and camera. Raw values are embedded only when
  explicitly requested, and the checksum is verified on restore.
- **Share links** (`#/explore?cfg=…`, deflate + base64url) contain configuration only. Demo
  datasets are regenerated by the recipient; for uploaded data the link carries name, shape and
  checksum, and the projection is recomputed only when an identical file is imported.

## Reading the PNG metadata

```python
from PIL import Image
print(Image.open("figure.png").text["LatentScope"])
```

## Reference values

`scripts/generate_references.py` regenerates every scientific fixture; the versions of Python,
NumPy, SciPy, scikit-learn and umap-learn used are stored in each fixture's `versions` field.
